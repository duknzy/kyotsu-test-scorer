# 共テナビ Pro | 共通テスト模試 自己採点・志望校傾斜配点＆二次逆算システム

大学入学共通テストの模試・過去問演習の自己採点から、志望校ごとの傾斜配点（圧縮配点・英語R/L比率換算）、A〜E判定シミュレーション、二次試験で必要な得点の逆算までを一元管理できるWebアプリケーションです。

## 主な機能

- **自己採点（素点＆大問別連動）**: 英語R/L・数I・A・数II・B・C・国語・理科・地歴公民・情報I（新課程1000点満点）に対応。大問別の得点入力と失点原因タグ（時間不足・ケアレスミス等）・復習メモを記録可能。
- **志望校・傾斜配点計算**: 大学・学部ごとに異なる各科目の換算満点や英語リーディング：リスニング比率を設定し、傾斜得点・得点率・判定を自動算出。
- **二次試験の必要得点逆算**: 総合合格最低点から共通テストの傾斜換算得点を差し引き、二次試験で何点（何%）必要かを自動計算。
- **タラレバ（What-If）シミュレーター**: 「もしこの科目があと○点高かったら判定や二次必要点はどう変わるか？」をスライダーでリアルタイム検証。
- **成績推移＆弱点分析**: 模試ごとの得点率推移グラフ、科目別バランスレーダーチャート、大問別の要復習リスト自動抽出。

## セットアップ・起動方法

```bash
npm install
npm run dev
```
